Contact Imminent privacy

Privacy information for Contact Imminent, a tactical strategy project from Inactive Studios LLC.

Development-stage notice

Contact Imminent is in active development and is not represented here as a released storefront build. This notice describes the current project state and will be revised before commercial release to match the data practices of the shipping version.

Current data practices

Inactive Studios LLC does not currently operate a player-account database for Contact Imminent, sell player personal information, or use this project page to create advertising profiles. Development builds may create local game data on the device used to run them.

Diagnostics, advertising, and storefronts

Production crash reporting, advertising, analytics, in-app purchases, and storefront integrations are not claimed by this notice until they are implemented in a release build. If introduced, this notice and the applicable Apple or Google privacy disclosures will be updated to identify the service and its data practices.

Data retention and deletion

Because Inactive Studios does not currently operate a player account or cloud-save service for Contact Imminent, there is no studio-hosted player profile or cloud save associated with this development-stage project. Information voluntarily sent to support is handled as described in the studio privacy policy.
