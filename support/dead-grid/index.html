Dead Grid support

Technical support and release information for Dead Grid from Inactive Studios LLC.

Active development

Dead Grid is currently in development. Platform availability, storefront links, and release timing will be published when confirmed.

Report an issue

Email support@inactivestudios.com and include the game title, version if known, device/platform, operating-system version, a description of the problem, and steps to reproduce it.

Screenshots are useful when they show the problem. Please do not include passwords, payment-card information, advertising identifiers, or unrelated personal information.

Availability

No Apple App Store or Google Play listing is represented as live from this page at this time. Official storefront links will appear here when a release is available.
